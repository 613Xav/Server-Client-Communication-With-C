# Server-Client-Communication-With-C

## 📋 Program Descriptions
1. server.c
Listens on port 60000 for incoming connections

Accepts one client at a time

Echoes received messages back to client

Type "shutdown" to stop the server

2. client.c
Connects to server at 127.0.0.1:60000

Sends user input to server

Displays server responses

Type "quit" to exit

## 🔄 Testing the System
Start server in Terminal 1

Start client in Terminal 2

Type messages in client - they should appear in server

Server echoes messages back to client

Type "quit" in client or "shutdown" in server to exit
